# FitFlow Redesign

Redesign of the FitFlow fitness app: AI-personalized workout plans, camera-based nutrition tracking, and a private social community layer.

## Tech Stack

- Frontend: React Native (iOS, Android, web)
- Backend: Node.js + Express
- Database: PostgreSQL
- Real-time / Social: Firebase (Firestore, Realtime Database)
- Authentication: Firebase Auth
- AI/ML: TensorFlow Lite (on-device) + Cloud ML/CV Kit
